# KenyDev — Templates de Landing Pages

Portfólio com **8 modelos de landing pages responsivas**, desenvolvidos em HTML, CSS e JavaScript puro.

## Estrutura dos modelos

- `landing_pages_vendaveis/01-agencia-digital/`
- `landing_pages_vendaveis/02-academia-fitness/`
- `landing_pages_vendaveis/03-restaurante-gourmet/`
- `mais_5_landing_pages/04-imobiliaria/`
- `mais_5_landing_pages/05-clinica-estetica/`
- `mais_5_landing_pages/06-curso-online/`
- `mais_5_landing_pages/07-fotografo/`
- `mais_5_landing_pages/08-saas/`

Cada modelo contém HTML, CSS, JavaScript e instruções de personalização dentro do respectivo pacote ZIP.

## Publicação na Vercel

O repositório contém `vercel.json` e `build.sh`. Durante o build, o script:

1. Copia o portfólio para a pasta de saída.
2. Mantém os dois pacotes ZIP disponíveis para download.
3. Extrai os oito modelos para a saída estática da Vercel.

Não é necessário instalar dependências npm nem executar um framework.

## Executar localmente

Extraia um dos ZIPs e abra o `index.html` de qualquer modelo no navegador. Para publicar alterações, mantenha os ZIPs e o script de build atualizados.

## Antes de entregar um modelo a um cliente

Substitua nome da marca, textos, preços, contatos, endereço, links de WhatsApp e imagens de demonstração. Confira também direitos de uso das imagens e demais materiais.
